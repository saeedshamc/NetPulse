# Build helper scripts / اسکریپت‌های بیلد

| Script | Platform | Produces |
|---|---|---|
| `build-windows.ps1` | Windows | NSIS `.exe` + `.msi` (WebView2 embedded) |
| `build-linux.sh` | Linux | `.AppImage` + `.deb` |
| `build-macos.sh` | macOS | `.dmg` + `.app` |
| `build-android.ps1` / `build-android.sh` | Android | `.apk` + `.aab` |
